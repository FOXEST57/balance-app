Comment installer l'application

  1. Autorisez les sources inconnues. Quand Android affiche « Bloqué par Play Protect » ou « Installation inconnue bloquée », appuyez sur Paramètres puis activez Autoriser cette source pour votre navigateur (Chrome, etc.).
  2. Acceptez l'installation. Une boîte de dialogue vous demande si vous voulez installer Balance. Appuyez sur Installer.
  3. Ouvrez l'app. Une fois installée, appuyez sur Ouvrir pour lancer Balance.
  4. Accordez les permissions. Autorisez le Bluetooth, la localisation et les notifications quand on vous le demande (nécessaires pour connecter votre balance).
